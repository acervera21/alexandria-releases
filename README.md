# Alexandria · instaladores

Alexandria es una app de escritorio para Windows que convierte tus carpetas en una biblioteca de
estudio: lectores y editores (PDF, Markdown con fórmulas, código, Word), búsqueda global y una IA
que propone y nunca impone.

Este repositorio solo guarda **los instaladores firmados** de cada versión; el código es privado.

## Instalar

1. Descarga **[Alexandria-setup.exe](https://github.com/acervera21/alexandria-releases/releases/latest/download/Alexandria-setup.exe)** (la última versión).
2. Ábrelo. Se instala solo para tu usuario, sin permisos de administrador.
   Si Windows SmartScreen avisa de un «editor desconocido», pulsa **Más información → Ejecutar de todas formas**.

## Actualizar

No hace falta volver aquí: al arrancar, Alexandria mira si hay una versión nueva, te enseña sus
novedades y se actualiza con un clic («Actualizar y reiniciar»). También desde la paleta
(`Ctrl+K` → «Buscar actualizaciones»).

Cada versión lleva `latest.json` y la firma del instalador: la app solo instala lo que está firmado
con la clave de Alexandria.
